# 雨笺

雨笺是一款 Android 卡片式便签应用，使用 Kotlin 开发，面向手机和平板的响应式布局。

## 核心特性

- 便签列表管理
- 每个便签内可创建多张卡片
- 每张卡片内包含多个行块
- 行块支持文本、富文和代码块
- 卡片拖拽排序
- 行块上移 / 下移排序
- 便签搜索
- 删除确认
- Wi-Fi 直连同步
- 蓝牙同步基础能力
- JSON 文件备份导出和导入
- 应用内日志 HTTP 代理，便于调试同步问题

## 数据结构

```text
Note 便签
  └─ NoteCard 卡片
       └─ NoteBlock 行块
```

## 同步流程

Wi-Fi 直连同步采用确认式导入流程：

1. 一台设备发现附近 Wi-Fi 直连设备。
2. 点击目标设备后发送本机同步包。
3. 对方收到后不会自动导入。
4. 对方在“待接收便签”列表中选择要接收的便签。
5. 点击“接收选中的便签”后写入本机数据库。

## 备份导入导出

- “导出备份”会生成一个 JSON 文件。
- “导入备份”会先解析文件。
- 解析后显示便签标题、卡片数量、行块数量和字符数。
- 用户勾选后才会导入。

## 调试日志

应用内置轻量 HTTP 日志服务：

```text
GET /health
GET /logs
GET /clear
```

默认端口：

```text
48621
```

USB 调试时可以使用：

```bash
adb forward tcp:48621 tcp:48621
curl http://127.0.0.1:48621/logs
```

## 构建

```bash
.\gradlew.bat :app:compileDebugKotlin
```

完整 APK 构建：

```bash
.\gradlew.bat :app:assembleDebug
```

## 当前限制

- 富文本目前是 Markdown 风格的基础能力，不是完整所见即所得编辑器。
- Wi-Fi 直连同步已具备发现、发送、接收和选择导入流程，但复杂冲突合并仍是后续增强项。
- 数据库升级迁移仍需继续完善，正式发布前不应使用破坏式升级。
